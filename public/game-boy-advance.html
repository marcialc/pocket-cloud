Game Boy Advance emulator in your browser

Pocket Cloud plays Game Boy Advance games in any modern browser using the mGBA emulator core, with cloud saves and online link cable play between friends.

Supported files and emulator

  • ROM files you provide, with the .gba extension. Pocket Cloud also recognizes a Game Boy Advance ROM by its header.
  • Emulator: the mGBA libretro core (MPL-2.0) inside RetroArch, loaded with Nostalgist.js, all running in your browser as WebAssembly. See Open-source licenses.
  • Screen: 240 × 160 pixels, scaled up to fit your display.

Buttons

A, B, L, R, Start, Select and the D-pad, with default keys Z, X, A (L), S (R), Enter and Shift. Keyboard, controller and touch are supported and remappable. See Controls.

Saves

Game saves are stored in your browser and, when you sign in, backed up to your account. See How Pocket Cloud works.

Link cable play

Signed-in players can link two Game Boy Advance games online with a friend to trade and battle. See Link cable play.

Other systems

Also supported: Game Boy and Game Boy Color. Pocket Cloud ships no games; you bring your own ROM files. See the FAQ.
