Game Boy emulator controls

You can play Pocket Cloud with a keyboard, a game controller or on-screen touch buttons, and you can remap the keys and controller buttons from the Controls panel.

Start is not a confirm button in most games: menus and dialogue usually confirm with A. You can rebind Start if Enter feels wrong.

Game controllers

Connected game controllers work through the browser's Gamepad support. By default the buttons follow the controller's standard layout, so on a Nintendo-style pad the right face button is A and the bottom one is B, and the left stick moves like the D-pad. You can remap controller buttons too.

The controller also gets you around the rest of Pocket Cloud, like a console: on the games page the D-pad or left stick moves from game to game and A starts the one picked; in menus and panels it moves between the buttons, A picks and B goes back. During a game, the Home (or Guide) button opens the menu, where you can pause, change settings or go back to your games. You can give the menu another button in Controls; some systems keep the Home button for themselves.

Touch controls

Touch screens get an on-screen gamepad. Buttons can be pressed together, so you can hold a direction and tap A at once. By default the on-screen buttons step aside while you play with a game controller; you can switch this in Account settings.

Remapping

Open Controls, pick a button, then press the key (or controller button) you want for it; Escape cancels. Bindings use physical key positions so they work on any keyboard layout, and a key can drive only one button at a time. Game Boy, Game Boy Color and Game Boy Advance have their own lists, except that Game Boy Color uses the Game Boy's. Controller and key settings are saved on your device, and keyboard controls also follow you to other browsers when you are signed in. "Reset to defaults" restores the original keys.

Other buttons

The game toolbar has pause and resume, sync now, reset, fullscreen, mute and volume. Emulation pauses when the tab is hidden. For two-player link play, see Link cable play.
