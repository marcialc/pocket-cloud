Game Boy Advance link cable play online

Pocket Cloud's link cable lets two signed-in friends link their Game Boy Advance games online to trade and battle, like two consoles joined by a cable.

What you need

  • Both players signed in with an email account (see how sign-in works).
  • Each other added as friends in the app's Friends panel.
  • A Game Boy Advance game open, and that game kept in your account's game library. Each player's link uses their own copy; no ROM is sent to the other player.

How it works

  1. In your game, go to the link room (in Pokémon games, upstairs in the Pokémon Center) and save.
  2. Open the Link cable button and choose Ask to link next to your friend. Only friends playing a game that links with yours can be picked. Your game waits while your friend is asked.
  3. Your friend's game pauses and asks them to accept or decline (on a controller, A accepts and B declines). When they accept, the two games are linked. While linked, both games run together on a link server, and each player sees and controls their own screen.
  4. Unplug (either player, or it times out if nobody is watching) and your save from the link comes back to your local game and your account.

Which games can link

  • Two copies of the same game file.
  • Pokémon Ruby, Sapphire, Emerald, FireRed and LeafGreen, with each other, from any region.

Other games need the same game file on both sides, because many games link differently in each region or version.

Good to know

  • Your friend needs to be in a game that links with yours and looking at it. If they don't answer within a minute, say no, leave the game or switch away from the app, the request ends, you're told why, and your game carries on. You can also stop waiting yourself.
  • Link play is for Game Boy Advance games only. Game Boy and Game Boy Color games are not linked.
  • The game pauses locally while you are plugged in, because it is running on the link server instead.
  • Link play runs on a link server and needs an internet connection; it does not work offline.
  • If a link fails, plugging in again starts over.
