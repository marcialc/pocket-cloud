Game Boy emulator in your browser

Pocket Cloud plays original Game Boy games in any modern browser using the binjgb emulator, with battery saves that can sync to your account.

Supported files and emulator

  • ROM files you provide, with the .gb or .sgb extension. Pocket Cloud also recognizes a Game Boy ROM by its header.
  • Emulator: binjgb (MIT license), compiled to WebAssembly and run in the page. See Open-source licenses.
  • Screen: 160 × 144 pixels, scaled up to fit your display.

Saves

In-game saves are stored in your browser and, if you sign in, backed up to your account so you can continue on another device. See How Pocket Cloud works.

Controls

D-pad, A, B, Start and Select, playable with keyboard, controller or touch. Keys are remappable. See Controls.

Other systems

Also supported: Game Boy Color and Game Boy Advance. Pocket Cloud ships no games; you bring your own ROM files. See the FAQ.
